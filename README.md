GlaucoGate is an advanced deep learning framework designed for automated, robust glaucoma screening from retinal fundus photographs. Addressing critical real-world medical AI bottlenecks, it features a dual-stream architecture combining a global field-of-view context stream with a weakly-supervised, saliency-anchored optic nerve head localizer. To combat multi-device domain shifts and low-quality acquisition artifacts , GlaucoGate integrates a multiplicative quality-aware gating mechanism (Q-CAF) that dynamically suppresses blurred or unreliable regions. Rigorously validated across in-domain and zero-shot external cohorts spanning four distinct fundus camera manufacturers, the system delivers superior diagnostic accuracy and high-specificity clinical reliability.
