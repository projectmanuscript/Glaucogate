GlaucoGate is a clinical grade deep learning framework engineered for automated and hardware agnostic glaucoma screening from retinal fundus photographs. Because glaucoma silently causes irreversible blindness and standard single stream deep learning models frequently fail when confronted with blurred screening images or cross camera domain shifts, this project introduces a quality aware multiplicative dual stream architecture built upon modern convolutional backbones. The pipeline begins with domain invariant preprocessing using tight circular field of view cropping, contrast limited adaptive histogram equalization in perceptual color space, Gaussian shade correction, and unsupervised clustering into color pseudo domains. The network evaluates each fundus photograph through two parallel pathways, a global stream equipped with a multi scale retinal nerve fiber layer module to capture wide anatomical context, and a local stream where a weakly supervised spatial transformer network automatically localizes and crops the optic nerve head without manual bounding box annotations and applies polar quadrant attention to measure neuroretinal rim thinning across the inferior, superior, nasal, and temporal regions. To prevent local optical artifacts such as cataract haze, motion blur, or camera glare from corrupting the diagnosis, a multiplicative quality aware cross attention fusion gate dynamically estimates pixel level visual reliability and suppresses degraded local features while falling back to safe global retinal context, supported by a selective abstention head that refers highly uncertain cases to human specialists. Optimized using a memory bank partial area under the curve objective for high specificity screening alongside group distributionally robust optimization for camera invariance, the system delivers reliable, interpretable, and real time diagnostic performance across diverse clinical imaging environments.
